# Vice Cover Studio

[![make.fun competition](https://make.fun/bounty/gta6-cover-art-01/badge/competition)](https://make.fun/bounty/gta6-cover-art-01)
[![make.fun rank](https://make.fun/bounty/gta6-cover-art-01/badge/rank)](https://make.fun/bounty/gta6-cover-art-01)
[![make.fun reward](https://make.fun/bounty/gta6-cover-art-01/badge/reward)](https://make.fun/bounty/gta6-cover-art-01)

An offline browser app that turns your photos and a caption into multi-panel cover art in the style of GTA 6's posters — Vice City sunset and neon grades, bold lettering, PNG export in the common post sizes. Photos never leave the machine.

Entry for make.fun bounty **gta6-cover-art-01** ("Make GTA 6 Cover Art").

## Run

```sh
node serve.ts
# open http://localhost:8080
```
